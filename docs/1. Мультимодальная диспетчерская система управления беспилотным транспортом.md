
## Назначение
Согласование маршрутов автономного городского транспорта **четырёх типов**, движущихся в разных средах.

## Типы транспорта
| Тип | Среда | Граф |
|---|---|---|
| Тротуарный ровер | Тротуары, пешеходные зоны | Граф тротуаров и переходов |
| Беспилотный автомобиль | Проезжая часть | Граф дорог |
| Дрон | Воздушные коридоры | Граф эшелонов |
| Катер / баржа | Фарватеры, шлюзы | Граф водных путей |

## Ключевые функции

1. **Приём заявок** — клиент выбирает тип транспорта под задачу доставки.
2. **Маршрутизация по модулям** — заявка направляется в модуль проверки, соответствующий среде (тротуар / дорога / воздух / вода).
3. **Проверка маршрута** — для каждого типа учитываются свои препятствия и правила:
   - ровер: лестницы, узкие проходы, толпа, занятые входы, переходы;
   - авто: перекопы, светофоры, пробки, закрытые полосы;
   - дрон: запретные зоны, эшелоны;
   - катер: шлюзы, разводные мосты, мели.
4. **Модуль рекомендаций** — при конфликте предлагает объезд, сдвиг времени, альтернативный вход/маршрут.
5. **Единая карта занятости** — четыре независимых слоя (sidewalk / road / air / water) с временными слотами по маршрутам.
6. **Межсредовое согласование** — координация разных типов транспорта в точках пересечения (например, ровер и авто на пешеходном переходе).
7. **Визуализация** — послойное отображение маршрутов с цветовой дифференциацией по типам.

## Архитектурный принцип
Модульное ядро: **новый тип транспорта = новый модуль проверки**, ядро и карта занятости не меняются. Сложность растёт линейно.
