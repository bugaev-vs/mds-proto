## Краткое техническое описание

**Назначение:**  
Программа формирует PDF-файл для печати на листах A4, которые затем склеиваются в бумажное поле размером 1×1 метр. Поле покрыто координатной сеткой с QR-кодами в каждой ячейке. Используется в школьных проектах по дискретной навигации миниатюрных машинок: камера, закреплённая сверху, распознаёт QR-код под машинкой и определяет её координаты на поле.

**Основные функции:**

- **Генерация PDF-документа** `field_1m_bw.pdf`, состоящего из 28 листов A4 (7 по ширине × 4 по высоте).
- **Построение поля 1000×1000 мм**, разбитого на сетку 20×20 клеток размером 50×50 мм каждая.
- **Создание QR-кода в каждой клетке** с уникальной координатой (например, `A1`, `B7`, `T20`).
- **Нанесение подписей осей** по краям поля: буквы `A…T` (строки, сверху вниз) слева и справа, цифры `1…20` (столбцы, слева направо) сверху и снизу.
- **Рисование линий сетки** — тонкие сплошные чёрные линии между клетками.
- **Рисование линий обрезки** — пунктирные линии только на внутренних стыках листов, где требуется резка.
- **Добавление реперных крестиков** в углах сетки для точного совмещения листов при склейке.
- **Поддержка настройки параметров** через переменные в начале скрипта: `CELL` (размер клетки), `COLS` (число столбцов), `ROWS` (число строк), `MARGIN` (поле вокруг сетки), `CUT_PAD` (запас до линии обрезки). Это позволяет генерировать поля других размеров и с другим количеством клеток.

**Технологии:**

- Python 3.8 или новее.
- Библиотеки: `reportlab` (генерация PDF, рисование линий, текста, вставка изображений), `qrcode` (создание QR-кодов), `pillow` / PIL (работа с изображениями, конвертация QR в 1-битный ч/б режим).
- Опционально — шрифт с поддержкой кириллицы (Arial, DejaVu Sans). В текущей версии весь текст на поле — латиница и цифры, поэтому шрифт не критичен.

**Запуск:**  
Команда `python a4_map.py`. После выполнения в текущей папке появляется файл `field_1m_bw.pdf`.

**Особенности печати и сборки:**

- Печать должна выполняться в масштабе **100% (Actual size)**, без опции «Fit to page», с минимальными полями принтера и отключённой экономией тонера.
- Листы обрезаются только по пунктирным линиям (внутренние стыки); внешние края поля не режутся.
- Склейка выполняется по реперным крестикам и QR-кодам на стыках, скотчем с обратной стороны.
- Контроль масштаба: сторона клетки на печати должна быть ровно 50 мм.

**Ограничения:**

- 20 клеток не делятся на 3 (число клеток по горизонтали на лист), поэтому последний лист по горизонтали короче — на нём 2 столбца вместо 3.
- QR-код уверенно читается камерой с высоты ~1 м при разрешении не ниже 1280×720. При слабой камере рекомендуется увеличить `CELL` и уменьшить `COLS`/`ROWS`.
- Глянцевая бумага даёт блики и мешает распознаванию — рекомендуется матовая.
