# Генератор поля 1×1 м с QR-сеткой

Программа создаёт PDF-файл для печати на листах A4, которые затем склеиваются
в большое поле 1×1 метр с координатной сеткой и QR-кодами в каждой ячейке.

## Назначение

Поле предназначено для школьных проектов по **дискретной навигации миниатюрных
машинок**. Камера, закреплённая сверху, распознаёт QR-код под машинкой и
определяет её координаты на поле.

## Что генерируется

- **PDF-файл** `field_1m_bw.pdf` из 28 листов A4 (7 по ширине × 4 по высоте).
- **Поле 1000×1000 мм**, разбитое на **20×20 клеток** по **50×50 мм**.
- **В каждой клетке** — QR-код с координатой (например, `A1`, `B7`, `T20`).
- **Подписи осей** по краям:
  - буквы `A…T` — слева и справа (строки, сверху вниз),
  - цифры `1…20` — сверху и снизу (столбцы, слева направо).
- **Линии сетки** — тонкие сплошные чёрные.
- **Линии обрезки** — пунктирные, только на внутренних стыках листов.
- **Реперные крестики** в углах сетки — для точного совмещения при склейке.

## Система координат

```
        1    2    3   ...  20
   ┌────┬────┬────┬────┬────┐
 A │ A1 │ A2 │ A3 │... │A20 │ A
   ├────┼────┼────┼────┼────┤
 B │ B1 │ B2 │ B3 │... │B20 │ B
   ├────┼────┼────┼────┼────┤
 C │ C1 │ C2 │ C3 │... │C20 │ C
   ├────┼────┼────┼────┼────┤
...│... │... │... │... │... │...
   ├────┼────┼────┼────┼────┤
 T │ T1 │ T2 │ T3 │... │T20 │ T
   └────┴────┴────┴────┴────┘
        1    2    3   ...  20
```

- **Буква** = номер строки сверху вниз (A — верхняя, T — нижняя).
- **Цифра** = номер столбца слева направо (1 — левый, 20 — правый).

## Требования

### Python
- Python 3.8 или новее.

### Библиотеки

Установка одной командой:

```bash
pip install reportlab qrcode[pil] pillow
```

| Библиотека | Назначение |
|---|---|
| `reportlab` | Генерация PDF, рисование линий, текста, вставка изображений |
| `qrcode` | Создание QR-кодов |
| `pillow` (PIL) | Работа с изображениями, конвертация QR в 1-битный ч/б режим |

### Шрифт с кириллицей (опционально)
Если в тексте нужны русские буквы, программа ищет один из шрифтов:

- `C:/Windows/Fonts/arial.ttf`
- `C:/Windows/Fonts/DejaVuSans.ttf`
- `/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf`

Если ни один не найден — используется `Helvetica` (без кириллицы).
В текущей версии весь текст на поле — латиница и цифры, поэтому шрифт
не критичен.

## Запуск

```bash
python a4_map.py
```

После выполнения в текущей папке появится файл **`field_1m_bw.pdf`**.

## Параметры (в начале скрипта)

```python
CELL = 50 * mm      # размер клетки (50 мм)
COLS = 20           # клеток по горизонтали
ROWS = 20           # клеток по вертикали
MARGIN = 20 * mm    # поле вокруг сетки на листе
CUT_PAD = 3 * mm    # запас от сетки до линии обрезки
```

Изменяя `CELL`, `COLS`, `ROWS`, можно получить другое поле
(например, `CELL = 100 * mm`, `COLS = 10`, `ROWS = 10` — поле 1×1 м
с 10×10 клеток и крупными QR).

## Печать

1. Открыть `field_1m_bw.pdf` в Adobe Acrobat Reader, Foxit Reader или аналоге.
2. В диалоге печати выбрать:
   - **Масштаб: Actual size / Реальный размер (100%)**.
   - **Не выбирать «Fit to page» / «По размеру страницы»**.
   - Поля принтера: **минимальные** или «None».
   - Режим экономии тонера: **выключить** (иначе QR будут бледными).
3. Напечатать все 28 листов.

### Проверка масштаба
Напечатайте первый лист и измерьте линейкой сторону клетки —
должно быть **ровно 50 мм**. Если 49 или 51 — проверьте настройки принтера.

## Резка

На каждом листе пунктирные линии показывают, **где резать**:

- **Внутренние стыки** (там, где лист стыкуется с соседним) — **пунктир есть**,
  режете по нему.
- **Внешние края поля** (граница большого квадрата 1×1 м) — **пунктира нет**,
  не режете.

Правило: режете только там, где есть пунктир.

### Схема для листа `[1,1]` (левый верхний угол поля)
- Сверху — нет пунктира (внешний край).
- Слева — нет пунктира (внешний край).
- Справа — пунктир (стык с `[1,2]`).
- Снизу — пунктир (стык с `[2,1]`).

### Схема для листа `[2,3]` (в середине)
- Все 4 стороны — пунктир.

### Схема для листа `[4,7]` (правый нижний угол)
- Справа — нет пунктира (внешний край поля).
- Снизу — нет пунктира (внешний край поля).
- Слева и сверху — пунктир.

## Склейка

1. Разложите листы по номерам:
   ```
   [1,1] [1,2] [1,3] [1,4] [1,5] [1,6] [1,7]
   [2,1] [2,2] ...
   [3,1] ...
   [4,1] ...
   ```
2. Совмещайте листы **по реперным крестикам** на стыках — они должны
   совпасть в один крестик.
3. Проверяйте совмещение по QR-кодам: `A3` на одном листе и `A3` на
   соседнем — это одна и та же клетка, они должны совпасть.
4. Склеивайте скотчем **с обратной стороны** (чтобы не закрывать QR).

### Проверка после склейки
- Расстояние между центрами двух соседних QR-кодов на стыке — **50 мм**.
- Линии сетки на стыке продолжают друг друга без разрыва.
- Внешний контур поля ровный, без ступенек.

## Структура скрипта

| Функция / блок | Назначение |
|---|---|
| `cell_name(col, row)` | Возвращает координату клетки (`A1`, `B7`…) |
| `make_qr_image(text)` | Генерирует QR-код в память, возвращает `ImageReader` |
| `draw_cross(c, x, y)` | Рисует крестик-репер в точке `(x, y)` |
| Основной цикл `for sy … for sx …` | Обходит все листы и рисует содержимое |
| Блок «QR-коды» | Рисует QR в каждой клетке |
| Блок «Линии сетки» | Рисует сплошные линии между клетками |
| Блок «Реперные крестики» | Рисует 4 крестика по углам сетки |
| Блок «Линии обрезки» | Рисует пунктир только на внутренних стыках |
| Блок «Подписи осей» | Рисует буквы и цифры по краям сетки |

## Ограничения

- **20 клеток не делятся на 3** (CELLS_X = 3), поэтому последний лист
  по горизонтали короче — на нём только 2 столбца вместо 3.
  Это нормально: при склейке он просто будет уже остальных.
- **QR-код читается камерой** с высоты ~1 м, если разрешение камеры
  не ниже 1280×720. При слабой камере — увеличьте `CELL` (например,
  до 70 мм) и уменьшите `COLS`/`ROWS` (до 14).
- **Глянцевая бумага** даёт блики и мешает распознаванию. Используйте
  матовую бумагу.

## Возможные ошибки

| Ошибка | Причина | Решение |
|---|---|---|
| `ModuleNotFoundError: No module named 'reportlab'` | Не установлены библиотеки | `pip install reportlab qrcode[pil] pillow` |
| «Чёрные квадраты» вместо букв | Шрифт без кириллицы | Установить Arial/DejaVu или использовать латиницу |
| QR не читается | Мелкий размер или бледная печать | Увеличить `CELL`, выключить экономию тонера |
| Листы не стыкуются | Неверный масштаб печати | Печать 100% (Actual size), проверить линейкой |
