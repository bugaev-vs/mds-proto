# Text-to-Speech Interview Generator (Silero TTS)

Скрипт для автоматической озвучки текстовых «интервью» с распределением реплик по голосам, добавлением фонового шума и экспортом в MP3.

Использует нейросетевую модель **Silero TTS v5 (русский язык)** и **ffmpeg** для постобработки звука.

---

## Возможности

- 🎙️ Синтез речи на русском языке (5 голосов Silero).
- 👥 Поддержка диалогов с ролями: разные голоса для ведущего и гостя.
- ✂️ Автоматическое разбиение длинных реплик на фрагменты.
- ⏸️ Вставка пауз между репликами.
- 🔊 Подмешивание фонового шума с заданным SNR (циклично по длине речи).
- 💾 Экспорт в MP3 (128 kbps, моно).
- 📦 Пакетная обработка всех подходящих `.txt` файлов в папке.

---

## Требования

### Системные
- **Python 3.10+**
- **ffmpeg** — должен быть доступен в `PATH`.

## Настройки

Все параметры задаются в начале файла в блоке `# ============ НАСТРОЙКИ ============`.

| Параметр | По умолчанию | Описание |
|---|---|---|
| `INPUT_DIR` | `.\interviews` | Папка с входными файлами |
| `PATTERN` | `int_*` | Маска для поиска файлов |
| `EXTENSIONS` | `{.txt}` | Расширения входных файлов |
| `SAMPLE_RATE` | `48000` | Частота дискретизации |
| `MAX_CHARS` | `800` | Макс. длина фрагмента текста |
| `PAUSE_SEC` | `0.35` | Пауза между репликами (сек) |
| `OVERWRITE` | `True` | Перезаписывать готовые MP3 |
| `MP3_BITRATE` | `128k` | Битрейт MP3 |
| `MP3_CHANNELS` | `1` | Каналы MP3 (1 = моно) |
| `KEEP_WAV` | `False` | Сохранять промежуточный WAV рядом с MP3 |
| `NOISE_FILE` | `.\interviews\noise_1.wav` | Файл фонового шума |
| `NOISE_SNR_DB` | `12.0` | Целевой SNR речи к шуму (дБ) |
| `NOISE_GAIN_DB` | `-3.0` | Дополнительная коррекция громкости шума (дБ) |
| `ALL_VOICES` | `aidar, baya, kseniya, xenia, eugene` | Доступные голоса Silero |
| `ROLE_ALIASES` | `ведущий→kseniya`, `гость→aidar` | Псевдонимы ролей |
| `DEFAULT_VOICE` | `kseniya` | Голос по умолчанию |

## Формат входного текста

Каждая строка — отдельная реплика. Роль указывается в начале строки через двоеточие.

### Поддерживаемые варианты

**С указанием роли (псевдоним):**
```
Ведущий: Здравствуйте, сегодня у нас в гостях...
Гость: Спасибо, рад быть здесь.
```

**С указанием голоса напрямую:**
```
aidar: Прямое указание голоса.
kseniya: Тоже работает.
```

**Без роли** — используется `DEFAULT_VOICE`:
```
Просто текст без указания роли.
```

### Правила
- Роль распознаётся регуляркой `^[А-Яа-яЁёA-Za-z]+\s*:\s*`.
- Если префикс не совпадает ни с одним голосом и ни с одним псевдонимом — вся строка озвучивается `DEFAULT_VOICE` (префикс не отбрасывается).
- Пустые строки игнорируются.

## Использование

1. Поместите `.txt` файлы в папку `interviews/` (имена начинаются с `int_`).
2. (Опционально) Положите `noise_1.wav` в ту же папку для добавления шума.
3. Запустите:
   ```bash
   python tts_script.py
   ```
4. Рядом с каждым `.txt` появится `.mp3` с озвучкой.

### Пример вывода

```
Найдено файлов: 2
  • int_01.txt
  • int_02.txt

Загружаю модель Silero...
Модель готова.

→ int_01.txt  →  int_01.mp3
  7 фрагмент(ов)
  [1/7] (kseniya) Здравствуйте, сегодня у нас в гостях...
  [2/7] (aidar) Спасибо, рад быть здесь...
  ...
  + шум: noise_1.wav (SNR ≈ 12.0 дБ, циклично)
  ✓ int_01.mp3  (142.3 сек, 2221 КБ)
```

## Как работает обработка

1. **Парсинг текста** — построчно, с определением голоса.
2. **Разбиение** — длинные реплики режутся по границам предложений/слов (не более `MAX_CHARS`).
3. **Синтез** — каждая реплика синтезируется выбранным голосом с расстановкой ударений и «ё».
4. **Сборка** — реплики склеиваются в единый массив с паузами `PAUSE_SEC`.
5. **Шум (опционально)** — через `ffmpeg` шум зацикливается и подмешивается к речи с расчётом усиления по RMS:
   ```
   noise_gain = speech_rms − noise_rms − SNR + GAIN
   ```
6. **Экспорт** — итог кодируется в MP3 (libmp3lame).

## Возможные проблемы

| Проблема | Решение |
|---|---|
| `ffmpeg не найден в PATH` | Установите ffmpeg и добавьте в `PATH` |
| Модель не загружается | Нужен доступ в интернет при первом запуске |
| Нет звука после микса | Проверьте `NOISE_SNR_DB` и `NOISE_GAIN_DB`; слишком громкий шум может «забить» речь |
| Долгий синтез на CPU | Модель работает на CPU; можно ускорить, перенеся её на GPU (требуется доработка кода) |
